Summary

피움(Pium)은 설문과 얼굴 사진을 기반으로 피부 상태를 7개 지표로 분석하고, 사용자에게 적합한 피부제품을 추천하는 개인화 피부 관리 서비스입니다. SWYP 웹 13기 팀 프로젝트를 기반으로 시작했으며, 이후 개인적으로 전반 구조를 재구성하고 기능과 운영 환경을 개선해 Toss Mini App과 웹서비스로 출시했습니다.

Backend

사진 기반 분석은 OpenAI API를 사용하여 사진의 시각 신호 추출과 상품 정보 구조화에 제한적으로 활용하고, 최종 피부 점수와 추천 결과는 백엔드의 규칙 기반 정책으로 결정합니다. 백엔드는 Spring Boot와 MySQL 기반으로 구성했고, DigitalOcean에서 Docker, Nginx, GitHub Actions, GHCR을 활용한 Blue-Green 방식으로 배포하고 있습니다.

Review

SWYP 웹 13기 팀 프로젝트로 시작한 서비스를 개인적으로 다시 정리하며, 백엔드 구조와 배포 흐름을 전반적으로 재구성했습니다. 전역 예외 처리, 공통 응답 구조, 로깅 필터를 직접 설계하며 확장 가능한 백엔드 구조를 고민했고, API 응답 구조를 지속적으로 개선하며 클라이언트가 사용하기 쉬운 데이터 전달 방식을 설계했습니다. 프론트엔드 구현과 개선에는 Codex를 활용했고, JVM 옵션 튜닝과 Caffeine 캐시 적용을 통해 제한된 서버 리소스를 효율적으로 활용하는 방법을 고민했습니다.
