팀 프로젝트에서 개인 서비스로

SWYP 웹 13기에서 만든 피부 진단 서비스를 개인 프로젝트로 이어 갔습니다. 백엔드 구조와 운영 환경을 다시 구성하고 Toss Mini App과 웹서비스로 출시했습니다.

진단 결과를 만드는 기준

사진만으로 판단하기 어려운 피부 상태는 설문 응답과 함께 해석했습니다. AI는 사진의 시각 신호와 상품 정보를 정리하는 역할을 맡고, 진단 점수와 추천 순서는 백엔드 정책에서 계산했습니다. 모델 응답이 달라져도 같은 기준으로 결과를 설명할 수 있도록 책임을 나눈 선택입니다.

출시 이후 다듬은 흐름

Toss Mini App과 웹에서 같은 진단 결과를 사용할 수 있도록 API 응답을 다시 정리했습니다. 사진 분석을 기다리는 동안 사용자가 보조 문항에 답하도록 처리 순서를 바꾸고, 제한된 서버 메모리 안에서 분석 세션을 유지할 수 있도록 JVM 설정과 캐시 범위도 조정했습니다.
