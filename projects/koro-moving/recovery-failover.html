Recovery, Cleanup & Failover

Failover Timeline

오래된 환경 자동 정리

기능 현재 운영 환경과 복구용 환경만 남기고 이전 배포를 정리합니다.

구현 정리 작업도 PostgreSQL에 저장해 서버가 재시작되거나 일시적으로 실패해도 다시 실행합니다.

복구용 환경 유지

기능 현재 서비스에 문제가 생기면 바로 전환할 수 있는 환경 하나를 유지합니다.

구현 현재 운영 이미지와 같은 digest로 검증된 환경만 standby로 인정하고, 나머지는 정리합니다.

장애 오판 방지

기능 순간적인 네트워크 지연만으로 운영 환경을 바꾸지 않습니다.

구현 Agent 연결 끊김과 공개 URL 3회 연속 실패가 함께 발생한 경우에만 장애로 판단합니다.

AWS 자동 전환

기능 온프레미스가 중단되면 사용자의 고정 URL을 정상 AWS 환경으로 연결합니다.

구현 새 인프라를 만드는 대신 이미 검증된 동일 이미지의 AWS 환경으로 Cloudflare origin을 변경하고 다시 확인합니다.

온프레미스 연결과 실제 서비스 응답이 모두 실패한 경우에만, 사전에 검증된 동일 이미지의 AWS 환경으로 전환합니다.
