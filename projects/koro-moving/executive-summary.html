Executive Summary

コロの引っ越し는 사용자가 소스 코드와 배포 환경을 선택하면 분석, 이미지 빌드, 배포와 정상 동작 확인을 자동으로 수행하는 플랫폼입니다. 같은 애플리케이션을 AWS와 온프레미스 사이에서 전환할 수 있습니다.

Project

형태SoftBank Hackathon 2026 팀 프로젝트

팀Camellia · 6명
담당Backend / Deployment Reliability

Core Stack

  • Control Plane TypeScript, Node.js, Fastify, PostgreSQL
  • Runtime Docker Compose, AWS ECS, ECR
  • Routing Cloudflare Tunnel, DNS, Health Check
  • Verification Vitest, k6, pg-boss

Development Process

일주일 동안 팀 전체에서 약 180건의 PR이 오갈 만큼 짧은 주기로 구현과 리뷰를 반복했습니다. 매일 Slack으로 설계와 진행 상황을 공유하고, 의견이 다른 경우에도 근거를 바탕으로 토론하며 방향을 정했습니다.

Field Feedback

대회 현장에서 Progate 관계자와 두 차례 인터뷰하며 배포 도구가 고려해야 할 사용자 환경과 설계 관점의 피드백을 확인하고 구현 방향에 반영했습니다.

My Focus

기능 배포된 서비스가 실제 URL에서 정상 동작하는지 확인하고, 온프레미스 장비가 중단되면 검증된 AWS 환경으로 전환합니다.

구현 배포 검증 작업, 온프레미스 실행 Agent, 재시작 복구와 환경 정리, 장애 감지 및 전환 흐름을 맡았습니다.
