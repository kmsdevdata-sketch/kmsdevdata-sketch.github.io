Executive Summary

コロの引っ越し는 사용자가 소스 코드와 배포 환경을 선택하면 분석, 이미지 빌드, 배포와 정상 동작 확인을 자동으로 수행하는 플랫폼입니다. 같은 애플리케이션을 AWS와 온프레미스 사이에서 전환할 수 있습니다.

Core Stack

  • Routing Cloudflare Tunnel, DNS, Health Check
  • Verification Vitest, k6, pg-boss

My Focus

기능 배포된 서비스가 실제 URL에서 정상 동작하는지 확인하고, 온프레미스 장비가 중단되면 검증된 AWS 환경으로 전환합니다.

구현 배포 검증 작업, 온프레미스 실행 Agent, 재시작 복구와 환경 정리, 장애 감지 및 전환 흐름을 맡았습니다.
