06 · 온프레미스 Agent

Agent가 사용자 장비에서 배포와 외부 연결을 이어 갔습니다

사용자가 온프레미스를 선택하면 전용 Agent가 배포 작업을 받아 컨테이너를 실행하고, 로컬 상태 확인과 외부 URL 연결까지 자동으로 처리합니다.

배포 흐름

같은 이미지를 실행하는 기준

Agent는 짧은 수명의 ECR 인증 정보로 이미지를 내려받습니다. 변경될 수 있는 tag 대신 image digest를 사용해 Control Plane이 승인한 결과물과 사용자 장비에서 실행되는 결과물을 일치시켰습니다.

배포마다 분리된 실행 공간

여러 배포가 한 장비에서 충돌하지 않도록 loopback port를 동적으로 할당하고 Docker Compose 단위로 실행 환경을 분리했습니다.

Agent가 연결하는 로컬과 외부 상태

Agent가 작업을 가져와 단계별 결과와 heartbeat를 보고합니다. 컨테이너의 로컬 응답을 먼저 확인한 뒤 Cloudflare Tunnel을 연결해 외부 접근 상태를 Dashboard에 반영했습니다.

재시작 이후의 상태 복원

실행 중인 컨테이너와 Tunnel 정보를 저장하고, Agent가 다시 시작되면 서버의 목표 상태와 비교합니다. 필요한 프로세스만 재연결해 기존 서비스를 이어서 운영하도록 했습니다.
