Deployment Flow

승인된 이미지 실행

기능 서버에서 빌드한 것과 같은 이미지를 사용자 장비에서 실행합니다.

구현 짧은 수명의 ECR 인증 정보를 발급하고, 변경 가능한 tag 대신 image digest로 내려받습니다.

배포별 실행 공간

기능 여러 배포가 포트 충돌 없이 독립적으로 실행됩니다.

구현 배포마다 loopback port를 동적으로 할당하고 Docker Compose로 컨테이너를 구성합니다.

상태 보고와 외부 연결

기능 Dashboard에서 온프레미스 배포 진행과 접속 상태를 확인합니다.

구현 Agent가 작업을 가져와 단계별 결과와 heartbeat를 보고하고, 로컬 확인 후 Cloudflare Tunnel을 연결합니다.

재시작 후 자동 복구

기능 Agent가 재시작돼도 기존 서비스와 Tunnel을 다시 연결합니다.

구현 실행 중인 컨테이너와 Tunnel 정보를 저장하고, 서버의 목표 상태와 비교해 필요한 프로세스를 복구합니다.
