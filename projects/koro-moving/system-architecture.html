System Architecture

배포 요청 관리

기능 분석, 빌드, 배포와 검증 진행 상태를 Dashboard에서 확인합니다.

구현 Control Plane이 작업 상태를 PostgreSQL에 저장하고 pg-boss로 다음 단계를 실행합니다.

환경별 배포

기능 하나의 빌드 결과를 AWS 또는 온프레미스에 배포합니다.

구현 AWS는 ECS Service로, 온프레미스는 Agent와 Docker Compose로 동일 image digest를 실행합니다.

AWS 실행 확인

기능 새 버전의 컨테이너가 실제로 실행된 경우에만 다음 단계로 이동합니다.

구현 배포가 생성한 Task Definition revision과 ECS rollout 상태를 추적합니다.

고정 URL 전환

기능 배포 환경이 바뀌어도 사용자는 같은 주소를 사용합니다.

구현 검증된 환경으로 Cloudflare origin을 변경하고 고정 공개 URL을 다시 확인합니다.

사용자가 접근하는 URL이 정상 응답해야 배포를 완료하고, 그렇지 않으면 기존 환경을 계속 제공합니다.
