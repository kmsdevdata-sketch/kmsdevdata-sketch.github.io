Verification & Idempotency

안정적인 응답 확인

기능 한 번의 우연한 성공이 아니라 서비스가 계속 응답하는지 확인합니다.

구현 최대 8회 요청하고 3회 연속 성공한 경우에만 통과시키며, 시간 초과와 연결 오류를 구분해 저장합니다.

실패 원인 조회

기능 어느 주소에서 몇 번째 확인이 실패했는지 Dashboard에서 추적합니다.

구현 시도마다 대상 URL, 응답 시간, 상태 코드와 실패 사유를 PostgreSQL에 기록합니다.

중복 실행 방지

기능 네트워크 재시도로 같은 요청이 반복돼도 배포는 한 번만 실행합니다.

구현 Job ID와 요청 내용의 SHA-256 fingerprint를 비교해 동일 요청은 기존 결과를 반환하고, 내용이 다르면 충돌로 거절합니다.

기존 서비스 보호

기능 새 환경이 실패해도 기존 서비스는 계속 요청을 처리합니다.

구현 후보 주소 확인 후 공개 주소를 다시 검증하고, 실패하면 Cloudflare origin을 이전 환경으로 되돌립니다.
