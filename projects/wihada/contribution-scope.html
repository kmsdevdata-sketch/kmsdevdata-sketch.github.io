문제 정의부터 배포까지 백엔드를 맡았습니다

4인 팀의 백엔드 개발자로 참여했습니다. 팀이 함께 결정한 제품 범위와 제가 직접 설계·구현한 서버 작업을 구분해 정리했습니다.

제품을 정하는 과정

  • 소셜 셀러 5명 현장 인터뷰 진행
  • IR 자료, PRD와 세부 기능 명세 작성 참여
  • PM·디자이너·프론트엔드와 기능 범위와 API 계약 조율
  • ERD와 상태 흐름으로 주문 모델 설명

실시간 상담과 결제

  • WebSocket/STOMP 채팅과 Redis Pub/Sub 구성
  • 주문서·주문확인서·결제 CTA를 타임라인에 통합
  • 트랜잭션 커밋 이후 이벤트 발행
  • 외부 결제 API와 내부 PaymentAttempt 연동
  • 재시도와 중복 클릭을 고려한 멱등 처리

주문 도메인과 API

  • 구매자·판매자 인증과 역할별 권한 검증
  • 스토어 운영 설정과 동적 주문서 양식
  • 주문서 제출, 주문확인서 발행과 수정 흐름
  • 결제, 픽업과 환불 상태 관리

배포 뒤 보완한 부분

  • 현재 주문 주기와 과거 이벤트의 상태 분리
  • 현재 참조 이미지와 주문 당시 스냅샷 분리
  • 판매자 캘린더, 매출 조회와 이메일 알림
  • AWS 배포와 GitHub Actions CI/CD 구성
