Contribution & Scope

4인 팀의 백엔드 개발자로 참여했습니다. 사용자 인터뷰와 기획 문서 작성부터 직군 간 기능 협의, 실시간 상담 흐름과 외부 결제 연동, 배포까지 서비스 개발 전 과정을 경험했습니다.

Discovery & Collaboration

  • 5명의 사용자 심층 인터뷰로 주문·상담 과정의 불편 확인
  • 대표 피드백을 바탕으로 사용자 가치와 사업 관점 검토
  • IR 자료, PRD와 세부 기능 명세 공동 작성
  • PM·디자이너·프론트엔드와 기능 범위 및 인터페이스 조율
  • ERD를 활용해 데이터 모델과 주문 흐름 설명

Realtime & Payment

  • WebSocket/STOMP 채팅과 Redis Pub/Sub 구성
  • 주문서·주문확인서·결제 CTA를 실시간 타임라인으로 확장
  • 트랜잭션 완료 이후 이벤트를 발행해 조회 시점 일관성 확보
  • 외부 결제 API 연동과 결제 시도·주문 상태 분리
  • 중복 요청을 고려한 멱등성과 예외 처리 적용

Backend Scope

  • 구매자·판매자 인증과 역할별 API 권한 검증
  • 판매자 입점, 스토어 정보와 운영 설정
  • 동적 주문서 양식, 제출과 주문확인서 흐름
  • 주문, 픽업과 환불 상태 관리

Operations & Improvement

  • 현재 주문 주기와 과거 이벤트의 상태 분리
  • 참조 이미지와 주문 당시 스냅샷 분리
  • 판매자 캘린더, 매출 분석과 이메일 알림 구현
  • AWS 배포 및 CI/CD 구성
