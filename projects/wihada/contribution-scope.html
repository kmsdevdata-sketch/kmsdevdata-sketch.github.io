Contribution & Scope

4인 팀에서 백엔드 개발자로 참여했습니다. 전체 서비스 범위와 개인 구현 범위를 구분하고, 아래에는 직접 설계·구현하거나 기존 흐름을 개선한 백엔드 작업만 정리했습니다.

Design & Implementation

  • 구매자·판매자 인증과 역할별 API 권한 검증
  • 판매자 입점, 스토어 정보와 운영 설정
  • 동적 주문서 양식, 제출과 주문확인서 흐름
  • 결제 시도, 주문, 픽업과 환불 상태 관리
  • Point3 결제 연동과 판매자 매출 조회
  • AWS 배포 및 CI/CD 구성

Collaboration & Improvement

  • 채팅 전송을 주문·결제 CTA 타임라인으로 확장
  • 주문서 확인 상태를 submission 단위로 분리
  • 현재 주문 주기 식별을 보강해 과거 이벤트와 분리
  • 현재 참조 이미지와 주문 당시 스냅샷 분리
  • 휴지통 상담에 새 주문서 제출 시 자동 복구
  • 판매자 캘린더, 매출 분석과 이메일 알림 구현
