Testing & Verification

Test Strategy

값 객체와 단순 도메인 규칙은 단위 테스트로 검증하고, 저장·조회, 트랜잭션, JPA 관계와 PostgreSQL 제약조건이 중요한 기능은 통합 테스트로 검증했습니다. 핵심 시나리오는 Testcontainers PostgreSQL을 사용해 실제 동작과 가까운 조건에서 반복 실행했습니다.

CI Verification

  • 컴파일 및 테스트
  • Spotless 포맷 검사
  • SpotBugs 정적 분석
  • JaCoCo 리포트 생성

Postman CLI Scenario

  • 구매자·판매자 등록과 역할별 인증
  • 입점 승인, 스토어 공지·갤러리·이미지 variant
  • 주문서 양식, 초안과 제출
  • 문의 목록, 상세, 타임라인과 읽음 처리
  • 주문확인서 preview, 발행, 수정 요청과 대체 발행
  • 판매자 대시보드와 매출 응답 계약

실제 Point3 결제가 발생할 수 있어 자동 Postman 시나리오에서는 결제 준비와 승인 호출을 제외했습니다. 측정하지 않은 테스트 개수나 커버리지 수치는 기재하지 않았습니다.

AI-assisted Development

AI 코딩 에이전트를 코드 탐색과 반복 구현에 활용했습니다. 도메인과 유스케이스 단위로 작업 범위를 제한하고 Testcontainers 통합 테스트, Postman CLI, 정적 분석과 배포 후 로그 확인을 완료 기준으로 사용했습니다.
