09 · Testing & Verification

도메인 규칙과 실제 사용자 흐름을 서로 다른 방법으로 검증했습니다

도메인 규칙은 빠르게 확인하되, 저장·조회와 트랜잭션처럼 데이터베이스 동작이 중요한 기능은 실제 PostgreSQL 환경에서 검증했습니다.

Test Strategy

값 객체와 단순 도메인 규칙은 단위 테스트로 빠르게 확인했습니다. 저장·조회, 트랜잭션, JPA 관계와 PostgreSQL 제약조건이 중요한 기능은 Testcontainers PostgreSQL을 사용해 실제 동작과 가까운 조건에서 반복 검증했습니다.

CI Verification

  • 컴파일과 자동 테스트
  • Spotless 포맷 검사
  • SpotBugs 정적 분석
  • JaCoCo 리포트 생성

Postman CLI Scenario

  • 구매자·판매자 등록과 역할별 인증
  • 입점 승인, 스토어 공지·갤러리와 이미지 variant
  • 주문서 양식, 초안 저장과 제출
  • 문의 목록, 상세 타임라인과 읽음 처리
  • 주문확인서 미리보기, 발행, 수정 요청과 대체 발행
  • 판매자 대시보드, 주문 목록과 매출 응답 계약

외부 결제를 제외한 주요 사용자 흐름은 Postman CLI로 자동화했습니다. Point3 연동은 결제 시도와 주문 상태 전이를 통합 테스트로 확인하고, 실제 결제 준비와 승인 흐름은 개발 환경에서 별도로 검증했습니다.

AI-assisted Development

AI 코딩 에이전트는 코드 탐색과 반복 구현에 활용했습니다. 변경 범위를 도메인과 유스케이스 단위로 나누고, 통합 테스트와 Postman CLI, 정적 분석, 배포 후 로그 확인을 거쳐 결과를 반영했습니다.
