Runtime

Spring Boot 애플리케이션은 ECS on EC2에서 컨테이너로 실행합니다. RDS PostgreSQL은 영속 데이터를, ElastiCache Valkey는 캐시와 Redis Pub/Sub을 담당합니다.

Configuration

설정과 Secret은 SSM Parameter Store에서 ECS Task Definition으로 주입합니다. 저장소와 배포 로그에는 실제 인증 정보가 남지 않도록 분리했습니다.

Health & Logs

Actuator Health Check로 ALB Target 상태와 배포 성공 여부를 확인하고 애플리케이션 로그는 CloudWatch Logs로 전달합니다.

Constraint

제한된 개발 인프라에서는 단일 ECS 인스턴스와 작은 desired count를 사용했습니다. 현재 배포를 블루·그린이나 완전한 고가용성 환경으로 표현하지 않았습니다.
