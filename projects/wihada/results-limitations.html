Results & Limitations

Results

  • 주문서 제출부터 상담, 주문확인서, 결제, 픽업과 환불까지 핵심 흐름 구현
  • 구매자와 판매자 웹 서비스에 실제 API 제공
  • Point3 결제 및 실시간 상담 타임라인 연동
  • 판매자 주문 목록, 캘린더와 매출 분석 구현
  • 비동기 이미지 variant 처리
  • AWS 개발 환경 배포와 CI/CD 구성
  • 통합 테스트와 Postman CLI 시나리오 구축

Current Limitations

  • 제한된 ECS 용량으로 고가용성과 무중단 배포 검증 부족
  • 대규모 WebSocket 연결 및 Redis Pub/Sub 부하 테스트 부족
  • 실제 Point3 결제를 자동 시나리오에서 제외
  • 운영자 기능과 판매자 정산 자동화 범위 제한
  • 분산 추적, 메트릭과 자동 장애 알림 보강 필요
  • Domain Model과 JPA Entity 통합에 따른 영속성 관심사 잔존

측정하지 않은 응답 시간, 처리량, 배포 횟수와 성공률은 결과로 기재하지 않았습니다.
