Deployment & Operations

Pipeline

main 브랜치에 변경이 반영되면 GitHub Actions가 테스트와 bootJar 빌드를 수행하고, Docker 이미지를 빌드해 ECR에 push합니다. 이후 기존 ECS Task Definition을 기반으로 새 revision을 등록하고 ECS Service를 업데이트합니다.

Runtime

운영 환경에서는 ALB health check를 통해 정상 task만 트래픽을 받도록 구성했습니다. ECS Task는 private subnet에 배치하고, 외부 진입은 Cloudflare와 ALB를 통해서만 받도록 정리했습니다.

private subnet의 ECS Task가 Cognito metadata와 AWS public endpoint에 접근할 수 있도록 NAT Gateway를 구성했습니다.
