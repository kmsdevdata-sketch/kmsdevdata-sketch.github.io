Current Limitations & Next Steps

현재 한계

  • RDS Security Group에 default SG가 임시 허용되어 있어 정리 필요
  • POSTGRES_PASSWORD, callback token 등 secret을 ECS 환경변수에 평문으로 두고 있어 이전 필요
  • 인프라가 콘솔 기반으로 구성되어 있어 IaC로 재현 가능하게 정리 필요
  • CloudFront custom domain은 아직 적용하지 않고 기본 도메인을 사용 중
  • DLQ redrive, alarm, retry 운영 정책은 MVP2에서 보강 필요

다음 단계

  • ECS Task 전용 SG 정리 및 RDS SG 최소 권한화
  • AWS Secrets Manager / Parameter Store 적용
  • CloudWatch Alarm 및 DLQ 복구 흐름 구성
  • Terraform 또는 AWS CDK 기반 IaC 정리
  • Asset tree view와 variant 상태 표시 개선
  • usage limit / rate limit / API key usage tracking 추가
