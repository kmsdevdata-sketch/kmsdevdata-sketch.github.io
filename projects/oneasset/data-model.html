06 · 데이터 모델

파일은 S3에, 상태와 메타데이터는 DB에 저장했습니다

Asset

Asset은 실제 파일 자체가 아니라 S3에 저장된 원본 파일의 메타데이터와 처리 상태를 관리하는 도메인입니다. DB에는 bucket, storageKey, contentType, sizeBytes, status 같은 정보를 저장합니다.

AssetVariant

Lambda가 생성한 파생 리소스를 표현합니다. 현재는 WebP variant 생성 흐름을 구현했고, type, storageKey, contentType, sizeBytes, width, height를 별도로 관리합니다.

ApiKey는 SecureRandom으로 생성하고 원문은 발급 시 한 번만 노출합니다. 서버에는 식별용 prefix와 서버 secret을 사용한 HMAC-SHA256 결과만 저장하여, DB 유출 시에도 실제 key가 직접 노출되지 않도록 설계했습니다.
