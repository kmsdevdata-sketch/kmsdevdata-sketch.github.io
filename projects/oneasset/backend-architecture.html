Backend Architecture

Backend Layer Diagram Controller, Application Service, Domain, Port, Adapter 계층 이미지 자리

백엔드는 Controller, Application Service, Domain, Outbound Adapter로 나눴습니다.

Application Flow

Controller는 HTTP 요청을 받아 command로 변환하고, Application Service는 파일 저장, 메타데이터 저장, 큐 발행, 상태 전이를 조율합니다.

Port & Adapter

S3, SQS, JPA 같은 외부 기술은 Port와 Adapter 뒤로 분리하여 핵심 애플리케이션 흐름이 특정 인프라 구현에 직접 묶이지 않도록 했습니다.

에셋 업로드는 단순 저장이 아니라 S3 저장, Asset PROCESSING 저장, SQS 발행까지 하나의 애플리케이션 흐름으로 관리합니다.
