04 · 백엔드 구조

업로드 흐름과 인프라 구현의 경계를 나눴습니다

업로드 요청에는 파일 저장, 메타데이터 기록, 처리 메시지 발행이 함께 필요합니다. 이 순서를 Application Service가 조율하고, 저장소와 큐의 구체적인 구현은 Port 뒤에 두었습니다.

애플리케이션 흐름

Controller는 HTTP 요청을 받아 command로 변환하고, Application Service는 파일 저장, 메타데이터 저장, 큐 발행, 상태 전이를 조율합니다.

외부 실패를 흐름 밖으로 격리

S3 저장과 SQS 발행은 각각 실패 조건이 다릅니다. Application Service는 업무 순서와 상태 전이에 집중하고, AWS SDK 호출과 JPA 저장은 Adapter가 맡도록 나눠 실패 지점과 테스트 대상을 구분했습니다.

에셋 업로드는 단순 저장이 아니라 S3 저장, Asset PROCESSING 저장, SQS 발행까지 하나의 애플리케이션 흐름으로 관리합니다.
