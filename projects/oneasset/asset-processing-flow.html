Asset Processing Flow

Sequence Diagram Client, Spring API, S3, RDS, SQS, Lambda, CloudFront 처리 흐름 이미지 자리

업로드 요청은 이미지 변환이 끝날 때까지 기다리지 않습니다.

  • Upload
    API는 원본 파일을 S3에 저장하고 Asset 메타데이터를 PROCESSING 상태로 저장한 뒤 SQS에 처리 메시지를 발행합니다.
  • Process
    Lambda는 SQS 메시지를 소비해 원본 이미지를 WebP variant로 변환하고 S3에 저장합니다.
  • Callback
    Spring internal callback API를 호출하여 변환 결과를 전달하고, Spring API는 callback token을 검증합니다.
  • Ready
    AssetVariant를 저장하고 원본 Asset 상태를 READY로 변경합니다.

    • 중복 callback 가능성을 고려해 variant 저장 시 storageKey 기준으로 이미 저장된 variant가 있는지 확인합니다.
