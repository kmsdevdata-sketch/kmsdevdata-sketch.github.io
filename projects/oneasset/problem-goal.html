02 · 문제와 목표

애플리케이션마다 반복되던 이미지 처리를 분리했습니다

문제

일반적인 애플리케이션에서는 이미지 업로드, 저장 경로 관리, CDN URL 조립, 리사이징 같은 로직이 기능마다 반복됩니다. 처음에는 단순 파일 업로드처럼 보이지만, 실제 운영 관점에서는 저장소 권한, 파일 경로 정책, 변환 실패 처리, CDN delivery, 상태 관리가 함께 필요합니다.

목표

OneAsset의 목표는 이 과정을 별도 API로 분리하는 것이었습니다. 외부 애플리케이션은 API Key와 사용자 정의 key만 알고 있으면 되고, OneAsset은 내부에서 S3 저장, 메타데이터 관리, 비동기 변환, delivery URL 제공을 담당합니다.
