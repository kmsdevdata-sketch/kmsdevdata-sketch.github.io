AWS Architecture

AWS Architecture Diagram Cloudflare, ALB, ECS on EC2, RDS, S3, SQS, Lambda, CloudFront 구조 이미지 자리

OneAsset의 API 요청은 Cloudflare를 통해 ALB로 들어오고, ALB는 private subnet에 배치된 ECS Task로 요청을 전달합니다.

Spring Boot API는 프로젝트/API Key 인증을 수행한 뒤 원본 파일을 S3에 저장하고, 에셋 메타데이터를 RDS에 저장합니다. 이미지 변환은 API 요청 흐름에서 직접 처리하지 않고 SQS 메시지로 분리했습니다.

Lambda는 SQS 메시지를 받아 원본 이미지를 읽고 WebP variant를 생성한 뒤, 처리 결과를 Spring internal callback API로 전달합니다. 이후 Spring API가 AssetVariant를 저장하고 원본 Asset 상태를 READY로 전이합니다.

현재 API 도메인은 Cloudflare Flexible SSL을 사용합니다. 외부 사용자는 HTTPS로 접근하지만, Cloudflare와 ALB 사이 origin 구간은 HTTP입니다.
